# Platon brand assets

Source marks for the Platon Code fork:

- `platon-logo-white.png` — official wordmark (from platon.com.br)
- `favicon.ico` — temple mark favicon (from platon.com.br)
- `generated/` — derived app icons, splash, and web favicons

User-facing product name: **Platon Code**.

Technical identifiers intentionally retained for compatibility:

- Package scope `@t3tools/*`
- Env vars `T3CODE_*`
- Data home `.t3` / `T3CODE_HOME`
- CLI binary / npm name `t3` (until a dedicated Platon CLI publish exists)
